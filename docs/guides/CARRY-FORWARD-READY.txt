📋 HOW IT WORKS (User Flow)

Admin Creates New Cycle:
1. Admin → Cycle Management
2. Create "2027 Annual" cycle
3. Modal asks: "Carry forward data?"
4. Click "Carry Forward"
5. System clones all finalized entries from 2026

User Sees Prefilled Entries:
1. User logs in
2. Dashboard shows entries with 📋 icon
3. Status: "Needs Confirmation"
4. All data prefilled from previous year!

User Reviews & Confirms:
1. Click "Edit" on entry
2. Review each step:
   - Company details ✓ (same)
   - Production volume ✓ (update if changed)
   - Segments ✓ (same)
   - Enzymes ✓ (confirm each)
   - Market share ✓ (confirm each)
3. Step 7: Enter confidence → Finalize
4. Done! 70% faster than re-entering!
