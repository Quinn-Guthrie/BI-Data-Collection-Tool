## 🗑️ Archive Policy

Files are archived when:
- They're superseded by newer documentation
- They're interim status reports (work is complete)
- They're feature completion markers (feature is done)
- They're outdated troubleshooting guides

Archives are kept for:
- Historical reference
- Understanding implementation evolution
- Tracking what was tried/fixed
